# Security Policy

If you believe you found a security issue in any SynK app, please do **not** open a public issue.

Report it privately:
- GitHub: **Security → Report a vulnerability** on this repository, or
- Email: *<add company security email>*

Include the app name, version, steps to reproduce and impact. We aim to reply within 7 days.

Only the **latest** version of each app is supported with fixes.
