# Kanmani

<img src="assets/kanmani-logo.png" alt="Kanmani logo" width="96">

**Malayalam system-wide transliteration for Windows.**
Type Manglish in English letters in **any** application and get Malayalam.
Example: type `njaan` and get **ഞാന്‍**.

## Features

- Works in Word, Notepad, browsers and any other Windows application.
- Runs in the background with no taskbar button; lives in the notification area (system tray).
- Turn ON/OFF with **Ctrl+M** or from the tray menu.
- Optional **Start with Windows**.
- Portable: a single `.exe`, carry it on a USB stick.

## Quick start

1. Download and double-click `Kanmani.exe`. A splash screen appears and the tray icon is added.
2. Green dot = ON, grey dot = OFF.
3. Type Manglish anywhere:

| Type | Get |
|------|-----|
| `njaan` | ഞാന്‍ |
| `kaNmaNi` | കണ്മണി |
| `sakha` | സഖ |

4. Press **Space, Enter, Tab** or punctuation (`. , ? !`) to finish a word. **Backspace** corrects inside the current word.
5. Right-click the tray icon for Pause/Resume, Start with Windows, About, Exit.

## Tips and notes

- If the app you type in runs **as Administrator**, run Kanmani as Administrator too, otherwise Windows blocks the keyboard hook.
- Keep your keyboard layout set to **English (US)** while typing Manglish.
- Kanmani only watches keystrokes to convert the current word. It does not log, store or send what you type.
  *(Confirm this statement matches the app's actual behaviour before publishing.)*
- To remove autostart: untick *Start with Windows* in the tray menu.
